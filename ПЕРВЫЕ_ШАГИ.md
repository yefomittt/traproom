# Первый запуск Traproom

Приложение уже установлено и запущено на этом компьютере. Для первого знакомства нужен только браузер.

1. Открой http://127.0.0.1:8765/.
2. Если появится вход, возьми логин и пароль из файла `local-access.txt` в этой папке.
3. Нажми «Новый проект». Введи своё название трека, темп, тональность и заметку. Сохрани.
4. Добавь две задачи, например «Подобрать ударные» и «Написать мелодию».
5. Нажми кружок возле одной задачи: прогресс станет 50%.
6. Обнови страницу. Проект и задачи должны остаться — они записаны в базу данных.
7. Нажми «Редактировать» и поменяй этап на «Аранжировка».

Три уже созданных трека — примеры. Можно изучать их и менять: настоящих пользовательских данных в них нет.

## Если после перезагрузки компьютера сайт не открывается

Запусти двойным щелчком `start-local.cmd` из этой папки. Пока пользуешься сайтом, оставь окно сервера открытым. Затем открой адрес выше. Для остановки нажми Ctrl+C в окне сервера.

Если сервер уже работает, запускать второй не нужно. Сервер слушает только 127.0.0.1 — это адрес твоего компьютера, не публичный сайт.

## Что уже есть на компьютере

- Python — программа, которая выполняет наш код.
- Django — библиотека, которая обрабатывает страницы, вход и сохранение данных.
- SQLite — база в файле `db.sqlite3`. Не удаляй его: там проекты и пользователи.
- Git — локальная история изменений исходников. GitHub — отдельный сайт; туда пока ничего не загружено.

Python и Django подготовлены в отдельной рабочей папке. Самостоятельно устанавливать программы сейчас не требуется. Когда начнём разбирать и менять код, можно открыть файлы прямо в редакторе приложения или отдельно установить редактор кода.

## Что будем разбирать вместе

1. Как нажатие «Сохранить» доходит от страницы до базы данных.
2. Как связаны пользователь, музыкальный проект и задача.
3. Как считается процент выполнения.
4. Как проверяется, что проект принадлежит вошедшему пользователю.
5. Как тест подтверждает, что приложение работает правильно.

Перед сдачей: проверить проект, опубликовать исходники и сайт, получить результат анализа качества, записать демонстрацию и подготовить отчёт по требованиям практики.
